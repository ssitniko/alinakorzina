## Переменные окружения
В проекте используется файл `.env` для хранения настроек, например:
```env
SECRET_KEY=ваш_секретный_ключ
DEBUG=False
ALLOWED_HOSTS=localhost,127.0.0.1
```
Важно: Не добавляйте файл .env в репозиторий — он включён в .gitignore.

## Запуск проекта
Для запуска через Docker выполните:
```bash
docker compose up --build
```
Проект будет доступен по адресу: `http://localhost:8000`

## Структура проекта
- alinakorzina/ — основной каталог с настройками Django.
- akorzina/ — приложение с логикой и шаблонами.
- .env — файл с конфиденциальными настройками (не хранится в репозитории).
- Dockerfile и docker-compose.yml — для контейнеризации и запуска.
